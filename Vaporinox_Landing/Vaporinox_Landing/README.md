# Landing de Vaporinox

1. Descomprime el ZIP.
2. En Visual Studio Code, ve a **Archivo → Abrir carpeta** y selecciona `Vaporinox_Landing`.
3. Para ver la página, abre `index.html` con doble clic desde el Explorador de archivos. Si ya tienes Live Server en VS Code, también puedes hacer clic derecho en `index.html` y elegir **Open with Live Server**.

`index.html` contiene el contenido y los enlaces. `styles.css` contiene el diseño adaptable y la animación de entrada. `assets/` incluye las imágenes, la fuente Roboto y su licencia.

Para ver la página localmente solo necesitas un navegador. Los destinos externos, como el catálogo y WhatsApp, requieren internet.
